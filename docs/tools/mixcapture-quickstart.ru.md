# mixcapture: быстрый старт (что куда подключить)

Задача: записать, как фирменное приложение пульта общается с пультом, и понять, какой параметр за что отвечает.
Вы двигаете фейдер или жмёте кнопку в приложении, а mixcapture показывает, какое сообщение изменилось. Перебирать
дампы пакетов вручную не нужно. Подробно (на английском): `docs/tools/mixcapture.md`.

## Перед началом
- **Усилители выключены** или мастер в зал на минимуме: во время записи фейдеры будут подниматься до +10 дБ.
- Записи могут содержать имена людей (названия каналов, сцен, устройств). Храним их только в закрытом репозитории
  `~/Desktop/dybyskz-mix/research/captures/<пульт>/<дата>/`. В публичный mixcore их класть нельзя (программа откажется).
- mixcapture сам ничего не отправляет в пульт. Всё меняет только фирменное приложение, которым управляете вы.

Сборка (один раз):
```bash
cd ~/Desktop/mixcore && go build -o ~/bin/mixcapture ./cmd/mixcapture
```

## Вариант А (рекомендуемый): Mac раздаёт Wi-Fi
Что куда:
- **Пульт** - кабелем Ethernet в Mac (через USB-C переходник на Ethernet).
- **Планшет или телефон** с фирменным приложением - по Wi-Fi к Mac.

Шаги:
1. Узнать IP пульта (в его сетевых настройках), например 192.168.1.62. Дать переходнику адрес из той же сети:
   ```bash
   networksetup -listallnetworkservices
   sudo networksetup -setmanual "USB 10/100/1000 LAN" 192.168.1.10 255.255.255.0
   ping -c 3 192.168.1.62
   ```
   (имя сервиса берите из списка, который покажет первая команда).
2. Системные настройки > Основные > Общий доступ > Общий интернет (кнопка (i)): раздавать **с переходника Ethernet**
   **для устройств через Wi-Fi**, задать имя сети и пароль, включить.
3. Подключить планшет к этой Wi-Fi сети. В приложении пульта **вписать IP пульта вручную** (192.168.1.62).
4. Запустить запись:
   ```bash
   mkdir -p ~/Desktop/dybyskz-mix/research/captures/<пульт>
   sudo mixcapture live -i bridge100 -console 192.168.1.62 \
     -out ~/Desktop/dybyskz-mix/research/captures/<пульт>/2026-10-12
   ```

Если приложение не умеет вписывать IP (только автопоиск), используйте вариант В.

## Вариант Б: ретранслятор (без переходника)
Mac, пульт и планшет в одной сети (роутер пульта). В приложении вписываете **IP Mac**, Mac пересылает всё пульту.
```bash
ipconfig getifaddr en0       # IP Mac, например 192.168.1.10
mixcapture relay -console 192.168.1.62 -listen 192.168.1.10 -udp 10024 \
  -out ~/Desktop/dybyskz-mix/research/captures/<пульт>/2026-10-12
```
Порт нужно знать заранее (для нового пульта сначала сделайте вариант А или В: порты будут в отчёте).

## Вариант В: управляемый коммутатор с зеркалированием порта
Пульт и точка доступа планшета - в коммутатор; порт пульта зеркалируется на порт, куда подключён Mac:
```bash
sudo mixcapture live -i en5 -console 192.168.1.62 -out ~/Desktop/dybyskz-mix/research/captures/<пульт>/2026-10-12
```
(`en5` - интерфейс переходника; список: `ifconfig`). Готовый файл pcap/pcapng с другого компьютера:
`mixcapture read -pcap file.pcapng -out ...`.

## Как работать во время записи
1. Запустили запись, **потом** открыли приложение и подключились к пульту. Через пару секунд появится
   `harvest 1 ... N keys`: это список почти всех параметров пульта с текущими значениями (файл `harvest.csv`).
2. Наберите `:s начало` и Enter - снимок состояния.
3. Для каждого органа управления: **напишите, что сейчас сделаете, нажмите Enter и сразу сделайте это** (в течение
   5 секунд), например `ch1 fader up`. Программа покажет `candidate: ...` - найденный параметр.
4. Закон фейдера: ставьте фейдер на известные отметки и пишите метку со значением:
   `ch1 fader = -inf`, `ch1 fader = -30`, `ch1 fader = -10`, `ch1 fader = 0`, `ch1 fader = +10`. Потом
   `:law <параметр>` (например `:law /ch/01/mix/fader`) - программа подберёт закон.
5. Сцены: `:s до`, вызвать сцену на пульте, `:s после` - увидите всё, что сцена поменяла.
6. `:q` - остановить. Отчёт `report.md` и таблицы `*.csv` в папке сессии передайте protocol-researcher.

Если что-то пошло не так: ошибка прав у `live` - запускайте через `sudo`; ничего не распознано - проверьте IP пульта
в `-console`.
